# Cube Assets

Optimized files for XiaoZhi ESP32 cube runtime.

Expected first files:

- `neutral.png` - first Stage 2 PNG download/cache/fallback test.
- `neutral.gif` - first optimized animated GIF test.
- `manifest.json` - stable raw URLs and constraints.

Rules:

- Keep each file under 250 KB.
- Prefer 100-150 KB.
- Use 240x240 canvas with the face visually around 200x200.
